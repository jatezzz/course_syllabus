# course_syllabus

A geometry and trigonometry course syllabus, typeset in LaTeX, with the source and the compiled PDF.

*Early work: LaTeX coursework.*

## Context

Written in March 2020 with a co-author. The files are named "Trabajo 2" (assignment 2), which suggests it was an assignment in a LaTeX course.

## What it shows

- A structured academic document in LaTeX: headers and footers with `fancyhdr`, logos, and multi-page tables.
- Advanced table layout with `tabularx`, `booktabs`, `multirow` and `colortbl` for the course schedule, outcomes and assessment.
- Spanish typesetting with `babel`, and math with the AMS packages.
- Clean separation of source (`.tex`), figures and the compiled PDF.

## Stack

LaTeX (pdfLaTeX), with babel, tabularx, booktabs, multirow, colortbl, fancyhdr and pstricks.

## Run it

Compile `Trabajo 2_Sílabo.tex` with a LaTeX distribution (TeX Live or MiKTeX), or open the included PDF.
